# Python Mini Projects

This repository contains a collection of Python mini projects that I built while learning the language from the ground up. Each project focuses on practicing and reinforcing core programming concepts through hands-on problem solving rather than simply following tutorials.

The projects gradually increase in difficulty, covering topics such as:

* Variables and data types
* User input and output
* Conditional statements
* Loops
* Functions
* Lists
* Dictionaries
* Random module
* Searching and updating data
* Menu-driven console applications
* Basic game logic

## Projects Included

* Student Grade Manager
* To-Do List
* Contact Book
* RPG Character Creator
* Quiz Game
* Word Guessing Game
* Number Guessing Game
* Dice Battle
* Pokémon-style Battle
* Inventory System
* Movie Database
* Bank Simulator

## Goal

The purpose of this repository is to document my progress as I continue learning Python and software development. Each project represents a step forward in understanding programming concepts, writing cleaner code, and improving problem-solving skills.

As I continue my learning journey, I will keep adding new and more advanced projects, eventually expanding into larger applications, game development, and machine learning.
